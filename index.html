About the Project

A flagship cloud computing portfolio project

Career HQ is a cloud-native, AI-powered career management platform designed to help students and early-career professionals organize every part of their career journey in one secure place.

The project serves as my flagship portfolio build and demonstrates full-stack development, cloud architecture, AWS integration, DevOps practices, database design, security, accessibility, and AI-assisted workflows.
